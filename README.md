# Fullstack MERN Blogging Website

Checkout website - https://youtu.be/J7BGuuuvDDk

This website features include -
1. Modern Blog Editor using Editor JS.
2. Dynamic Blog Pages on dynamic urls.
3. Dedicated Users Profile.
4. Dedicated dashboard to manage blogs either published or draft.
5. Blog Post Analytics, editable and deletable.
6. Like interaction on Blogs with feature to comment on the blog.
7. Reply to comments. ( A nested Comment System )
8. Every interaction on site stores as a notification for their respective users.
9. Edit profile option.
10. Also user can change login password from profile.
11. Its mobile responsive with modern design. 

And much more.
